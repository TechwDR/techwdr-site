# Security policy

techwdr.com is a static site: no forms, no accounts and no server code.

## Reporting a vulnerability
Please report security issues privately. Either:
- use GitHub's **Report a vulnerability** button on this repository's Security tab (private vulnerability reporting), or
- email [privacy@techwdr.com](mailto:privacy@techwdr.com).

Please don't open a public issue for a security problem. Include the page or file, what you found and how to reproduce it. You can expect a reply within 7 days.

## Scope
The site code in this repository and the response headers in `public/_headers`. Third-party services (Netlify, YouTube, LinkedIn, X) have their own programs.
